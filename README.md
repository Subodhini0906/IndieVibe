# Website

**Website** is a platform designed to help busy men and women find nearby boutiques and easily book appointments without having to visit in person. This website allows users to browse boutiques, read reviews, and secure appointments, saving them time and effort. It’s built with **Next.js**, **Tailwind CSS**, and **TypeScript**, providing a sleek, modern, and responsive web experience.

## Features

- **Boutique Discovery**: Search for boutiques based on gender (Men's and Women's) and location.
- **Appointment Booking**: Users can book appointments directly with boutiques.
- **Reviews**: Check out reviews and ratings to make informed decisions.
- **Responsive Design**: Fully responsive design built using **Tailwind CSS**, ensuring optimal performance on all devices.
- **Authentication**: Secure user login and registration via **NextAuth.js**.
  
## Technologies Used

- **Next.js**: React framework for building server-rendered applications.
- **Tailwind CSS**: Utility-first CSS framework for rapid UI development.
- **TypeScript**: Provides type safety for better maintainability and scalability.
- **NextAuth.js**: Authentication system for managing user sessions.
- **PostCSS**: CSS tool used for optimizations.
